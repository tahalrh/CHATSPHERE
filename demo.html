Comment l'intégration fonctionne :
Cette page est un site normal. Le chatbot est ajouté avec une seule ligne tout en bas du HTML :

<script src="http://localhost:3001/widget/widget.js" data-bot-id="VOTRE_BOT_ID" data-server="http://localhost:3001"></script>

C'est tout. Le widget apparaît automatiquement en bas à droite sur n'importe quel site — WordPress, React, HTML statique, peu importe.
